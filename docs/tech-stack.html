01 · 内容层

五章 + 三枚小样 + 速查卡

审批门控 · 降级链 · 日志时间线——三个可以直接上手玩的交互小样，全部为原生 DOM 动画；外加 4 张手绘插图与 1 张速查卡。

02 · 前端架构

单文件 · 零框架

整站一个 index.html：内联设计系统（CSS 变量：靛蓝 + 朱砂）、原生 JS 小样、无构建、无依赖、无第三方脚本。

03 · 字体

霞鹜文楷 · 自托管子集

LXGW WenKai（OFL）按本页用字子集化：742 字形 × 2 字重，每个 woff2 约 160KB，preload 首屏字体。

04 · 视觉物料

手绘风插图 · GPT 系生成

4 张涂鸦插图由 GPT 系图像模型生成（xjbh 优先、噜皮兜底），经三轮目检与语义核对后入场。

05 · 工程管线

node 拼接 + API 部署

正文分片撰写 → node 脚本拼接进模板（含配色置换 19 项）→ 凭据直连 GitHub REST API 建仓开 Pages。

06 · 质量门槛

页内小样都带"人话验收"

每个小样都可在真实浏览器里逐步走查：门控三段状态、降级链全断停手、日志时间线可脱敏开关——失败路径优先被验收。
